# LIVE LOG — 初期プロトタイプ

iPhone / PC のブラウザで使うライブ記録アプリです。

## 現在できること
- ライブ実績の追加・編集・削除
- 開催日、アーティスト、ツアー、会場、都道府県の記録
- チケット・交通・ホテル・その他費用の記録と合計
- セットリスト（1行1曲）の登録
- 登録楽曲・披露公演数の自動集計
- アーティスト別・費用項目別の集計
- JSONバックアップの書き出し・読み込み
- スマホ・PCの画面幅に対応

## 起動方法
Node.js 20 以降をインストールしてから、プロジェクトフォルダで実行。

```bash
npm install
npm run dev
```

表示されたURLをブラウザで開きます。

## GitHubに置く
GitHubで空のリポジトリを作成し、このフォルダの中身をpushします。
GitHub Desktopを使う方法でも構いません。

## 保存について（重要）
この初期版は、まず試せるようにブラウザの localStorage に保存します。
**この状態ではiPhoneとPCでデータは同期されません。** ブラウザのデータ消去で消える可能性があるため、定期的にJSONバックアップを保存してください。

## クラウド同期を有効にする次の工程
1. Supabaseでプロジェクトを作成
2. `supabase/schema.sql` をSQL Editorで実行
3. `.env.example` を `.env.local` にコピー
4. SupabaseのProject URLとanon keyを設定
5. 認証画面とCRUD同期処理を接続（この初期版では接続設定欄のみ用意）

Supabaseの `service_role` key は絶対にフロントエンドへ置かないでください。

## Excelデータ移行について
元Excelには「費用」「演奏曲(BUMP)」「演奏曲(乃木坂)」「当落貰」のシートが含まれています。
初期版ではExcelを直接取り込む処理はまだありません。まず元データの列構造と公演単位の対応関係を確認し、既存履歴を壊さない移行用CSVを作成してから取り込みます。
